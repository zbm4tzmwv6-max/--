# BJCP 简体中文网考模拟题库 · V0.3

46 道原创备考题（非 BJCP 官方真实题库），支持判断/单选/多选、限时练习、逐题解析、错题本、移动端和自动恢复未完成的答题。

## 打开方式

备用静态访问地址：https://raw.githack.com/zbm4tzmwv6-max/--/main/index.html

> RawGitHack 是第三方公共代理，首次访问 HTML 可能要求确认。建议 GitHub 仓库 Settings → Pages → Deploy from a branch → main / root，启用后使用 https://zbm4tzmwv6-max.github.io/--/ 。Pages 未启用前不可声称该网址已上线。

iPhone 使用 Safari 打开网页，分享 → 添加到主屏幕。

## 记录及隐私

- 错题和成绩仅存在打开网站的浏览器本地（localStorage），不传到 GitHub。
- 做题进度自动保存；重新进入首页后点击「继续答题」。
- 清理 Safari 网站数据、更换设备或浏览器会丢失记录。
- Service Worker 会在支持 HTTPS 和相应站点权限时缓存本站首页与图标，但离线访问依赖实际浏览器和宿主环境。
